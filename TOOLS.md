# Tools & Technologies Used

A brief overview of the tools and technologies used to develop and replicate this website.

**1. AI Development Tool**
- **Cursor IDE** Used for website analysis, AI-assisted coding, component development, Three.js implementation, refactoring, and debugging.

**2. Programming Languages**
- **TypeScript (TS/TSX):** Application logic and React components.
- **GLSL:** Custom 3D shaders for atmospheric effects and procedural ocean waves.
- **HTML5:** Semantic markup, Canvas, and SVG elements.
- **CSS3:** Responsive layouts, animations, transitions, and visual styling.

**3. Frameworks & Libraries**
- **React 18:** Component-based frontend development.
- **Three.js:** Interactive 3D globe, ocean, container ship, and WebGL animations.
- **Lucide React:** Interface icons.

**4. Build Tools**
- **Vite 6:** Development server and production builds.
- **Node.js & npm:** Runtime and dependency management.
- **PostCSS & Autoprefixer:** CSS processing and browser compatibility.

**5. Inspection & Integration**
- **Chrome DevTools:** Website inspection, debugging, and responsive testing.
